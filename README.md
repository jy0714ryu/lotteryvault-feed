# lotteryvault-feed

Static results feed for the Lottery Vault Android app (`com.quantlog.lotteryvault`), served by GitHub Pages at
https://jy0714ryu.github.io/lotteryvault-feed/v1/ .

Generated by `feed/build_feed.py` in the app repo (stdlib only). Do not edit files by hand: published values are
immutable and the app verifies `history_sha256`.

Source: New York State Gaming Commission via data.ny.gov (Texas Lottery CSV as a cross-check).
Unofficial copy; in the event of a discrepancy, official drawing results prevail.
Not affiliated with or endorsed by Powerball, Mega Millions, MUSL or any state lottery.
